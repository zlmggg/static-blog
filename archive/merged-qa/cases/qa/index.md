# 问与答

> 把原来按主题拆开的问答，合并成按**业务域**组织的 7 篇文档；每篇内部按“部署前 → 部署 → 运行排障”的顺序排列。  
> 这里不要求你参与答题，直接当排查手册读：先看问题定位知识点，再看「答」里的判断依据和命令。

## 怎么读

1. **部署前**：先看选型、容量、架构类问题，避免上线后再返工。
2. **部署阶段**：看权限、存储、网络、镜像、数据库主从、流水线这些“落地时会卡住”的点。
3. **运行阶段**：看资源、磁盘、DNS、502/504、Pod 异常、慢查询、告警这些“跑起来才暴露”的问题。
4. 每篇末尾都有「延伸阅读」，需要命令细节时再跳转到速查手册或对应专题。
