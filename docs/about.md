## 这是什么网站

**sresec.com（禾光 - SRE Notes）** 是一个个人 SRE 运维知识库，用来沉淀 Linux 运维、服务部署、监控告警、容器与云原生、自动化等方向的学习笔记和实战方案。

核心目的是：**自己遇到问题时，能快速搜到、快速回忆处理方法**；同时也希望这些可复制的方案，能帮到同样在路上的运维同学。

## 如何使用这个站

1. **最快：按 `Ctrl+K`（Mac 为 `Cmd+K`）打开搜索**，输入命令或报错关键词，直接跳转。
2. 想系统浏览：从顶部「操作指南」进入各板块的聚合页。
3. 忘了命令：查「速查手册」长文档，用右侧「本页目录」跳转。
