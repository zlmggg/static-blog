# 07 · P2-3：蓝绿发布（app-green + Nginx 切流）

| 项目 | 内容 |
|---|---|
| **所属阶段** | P2（第二天） |
| **前置条件** | P2-1、P2-2 完成；四台 app 的宿主机还有 ≥60G 空闲 |
| **预计耗时** | 60 分钟 |
| **完成标志** | 页面版本从 `v1` 切到 `v2`、节点从 blue 变 green；**回滚一次**；Redis 切主后页面不报错 |
| **下一步** | P3（GitLab / Jenkins / Harbor） |

**这一步建 2 台：**

| VMID | 主机名 | 角色 | 规格 |
|---|---|---|---|
| 132 / 133 | app-green-01/02 | 新版本（v2，带哨兵） | 2C/3G/20G |

**蓝绿的本质**：两套环境都在跑，Nginx 的 upstream 指向谁，流量就去谁。切换 = 改一个文件 + reload，秒级；回滚 = 改回去。

## 步骤 2 · 在 green 上部署 v2（20 分钟）

**在哪台**：app-green-01（132）、app-green-02（133）
**目的**：起 v2 应用，**连哨兵**而不是直连 redis-01
**开始前**：步骤 1 的两台能 ping 通

**操作**：

```bash
# 在 bastion 上执行（ubuntu）
for ip in 10.0.0.132 10.0.0.133; do
  scp -q ~/demo-app.py ubuntu@$ip:/tmp/
done
```

```bash
# 在 bastion 上执行（ubuntu）—— 两台执行同样的安装
for ip in 10.0.0.132 10.0.0.133; do
ssh -o StrictHostKeyChecking=no ubuntu@$ip "bash -s" <<'EOS'
sudo apt install -y python3-venv python3-pip
sudo mkdir -p /opt/edu-app
sudo cp /tmp/demo-app.py /opt/edu-app/app.py
sudo python3 -m venv /opt/edu-app/venv
sudo /opt/edu-app/venv/bin/pip install -q -i https://pypi.tuna.tsinghua.edu.cn/simple \
  flask pymysql redis

sudo tee /etc/systemd/system/edu-app.service >/dev/null <<'EOF'
[Unit]
Description=Edu demo app
After=network-online.target

[Service]
User=www-data
Group=www-data
WorkingDirectory=/opt/edu-app
Environment=APP_VERSION=v2
Environment=DB_HOST=10.0.0.150
Environment=DB_USER=edu
Environment=DB_PASS=【实验密码】
Environment=DB_NAME=edu
Environment=REDIS_SENTINELS=10.0.0.160:26379,10.0.0.161:26379,10.0.0.162:26379
Environment=REDIS_MASTER_NAME=mymaster
ExecStart=/opt/edu-app/venv/bin/python /opt/edu-app/app.py
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
EOF

sudo chown -R www-data:www-data /opt/edu-app
sudo systemctl daemon-reload
sudo systemctl enable --now edu-app
sleep 2
curl -s localhost:8080/healthz
EOS
done
```

**应该看到**：两次 `ok`。

验证 v2 自己能读到数据：

```bash
# 在 bastion 上执行（ubuntu）
curl -s http://10.0.0.132:8080/ | grep -E "版本|Redis 访问计数|数据库连通"
```

**应该看到**：`v2`、计数是个数字、`YES`。

**失败怎么办**：
- 计数是 `error:` → 哨兵没起来，回 `05` 步骤 8
- `healthz` 不是 ok → `sudo journalctl -u edu-app -n 30 --no-pager`

## 步骤 3 · 切流到 green（5 分钟）

**在哪台**：nginx-01（120）、nginx-02（121）
**目的**：把 upstream 从 blue 改成 green
**开始前**：步骤 2 的 132/133 都能返回 v2

**操作**：

```bash
# 在 bastion 上执行（ubuntu）—— 两台 Nginx 都改
for ip in 10.0.0.120 10.0.0.121; do
ssh -o StrictHostKeyChecking=no ubuntu@$ip "bash -s" <<'EOS'
sudo cp /etc/nginx/conf.d/00-upstream.conf /etc/nginx/conf.d/00-upstream.conf.blue
sudo tee /etc/nginx/conf.d/00-upstream.conf >/dev/null <<'EOF'
upstream app_pool {
    server 10.0.0.132:8080 max_fails=2 fail_timeout=5s;
    server 10.0.0.133:8080 max_fails=2 fail_timeout=5s;
}
EOF
sudo nginx -t && sudo systemctl reload nginx
EOS
done
```

**应该看到**：两行 `nginx: configuration file ... test is successful`。

**失败怎么办**：
- `nginx -t` 失败 → `sudo cat /etc/nginx/conf.d/00-upstream.conf` 看是否被写坏；用 `.blue` 备份还原

## 步骤 5 · 回滚演练（5 分钟）

**在哪台**：nginx-01/02
**目的**：证明回滚是秒级的
**开始前**：步骤 4 是 v2

**操作**：

```bash
# 在 bastion 上执行（ubuntu）—— 用备份还原
for ip in 10.0.0.120 10.0.0.121; do
ssh -o StrictHostKeyChecking=no ubuntu@$ip \
  "sudo cp /etc/nginx/conf.d/00-upstream.conf.blue /etc/nginx/conf.d/00-upstream.conf && sudo nginx -t && sudo systemctl reload nginx"
done

curl -s http://10.0.0.119/ | grep 版本
```

**应该看到**：`v1`——回滚完成，全程没停服务。

再切回 v2（后面还要用）：

```bash
# 在 bastion 上执行（ubuntu）
for ip in 10.0.0.120 10.0.0.121; do
ssh ubuntu@$ip "sudo tee /etc/nginx/conf.d/00-upstream.conf >/dev/null <<'EOF'
upstream app_pool {
    server 10.0.0.132:8080 max_fails=2 fail_timeout=5s;
    server 10.0.0.133:8080 max_fails=2 fail_timeout=5s;
}
EOF
sudo nginx -t && sudo systemctl reload nginx"
done
curl -s http://10.0.0.119/ | grep 版本
```

**应该看到**：`v2`。

## 步骤 6 · 金丝雀 10%（10 分钟，可选）

**在哪台**：nginx-01/02
**目的**：新版本先接 10% 流量
**开始前**：步骤 5 已切回 v2

**操作**：

```bash
# 在 bastion 上执行（ubuntu）
for ip in 10.0.0.120 10.0.0.121; do
ssh ubuntu@$ip "sudo tee /etc/nginx/conf.d/00-upstream.conf >/dev/null <<'EOF'
upstream app_pool {
    server 10.0.0.130:8080 weight=9;
    server 10.0.0.131:8080 weight=9;
    server 10.0.0.132:8080 weight=1;
    server 10.0.0.133:8080 weight=1;
}
EOF
sudo nginx -t && sudo systemctl reload nginx"
done
```

打 20 次，数版本：

```bash
# 在 bastion 上执行（ubuntu）
for i in $(seq 20); do curl -s http://10.0.0.119/ | grep -o 'v[12]' | head -1; done | sort | uniq -c
```

**应该看到**：`v1` 大约 18 次、`v2` 大约 2 次（10%）。

**失败怎么办**：
- 全是一边 → weight 写错，`sudo nginx -T | grep weight`
