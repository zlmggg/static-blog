| 项目 | 内容 |
|---|---|
| **所属阶段** | P3（第三天） |
| **前置条件** | P3-1 完成：若依能登录、MinIO 能上传 |
| **预计耗时** | 60 分钟 |
| **完成标志** | 若依左侧出现"用户搜索"菜单，点开能搜到 `sys_user` 里的人，数据来自 ES |
| **下一步** | `11-P3-3若依蓝绿发布.md` |

## 为什么不用改代码

若依本身**没有 ES 集成**，但运维可以用"旁路"方式把数据送进 ES：

```
MySQL(ry-cloud.sys_user)                      ← 若依正常写库，代码不动
        │  Logstash JDBC（每分钟增量）
        ▼
   Elasticsearch(ry-user 索引)
        │  Nginx 反向代理 /es/
        ▼
   一个静态搜索页  ← 挂在若依菜单里作为"外链"
```

**你要写/改的只有三样：Logstash 配置、一个 HTML 页面、Nginx 配置。没有一行 Java。**

> 这和你上次"改一堆代码"的区别：这次 ES 是**旁路**，若依完全不知道它的存在；哪天 ES 挂了，若依照常用。

## 步骤 0 · 准备 JDBC 驱动（10 分钟）

**在哪台**：es-03（182，Logstash 所在）
**目的**：Logstash 需要 MySQL 驱动才能读库
**开始前**：P3-1 验收通过

**操作**：

```bash
# 在 bastion 上执行（ubuntu）
ssh ubuntu@10.0.0.182
```

```bash
# 在 es-03 上执行（ubuntu）
sudo mkdir -p /usr/share/logstash/vendor/jdbc
sudo wget -q -O /usr/share/logstash/vendor/jdbc/mysql-connector-j-8.0.33.jar \
  https://maven.aliyun.com/repository/public/com/mysql/mysql-connector-j/8.0.33/mysql-connector-j-8.0.33.jar
ls -lh /usr/share/logstash/vendor/jdbc/
```

**应该看到**：一个 2MB 左右的 jar。

**失败怎么办**：
- 下载 404 → 浏览器打开阿里云仓库找可用版本，换版本号
- 文件是 HTML（下载失败）→ `file` 命令看类型，重新下

## 步骤 1 · 加一条 JDBC 管道（15 分钟）

**在哪台**：es-03（182）
**目的**：每分钟把 `sys_user` 的增量同步到 ES
**开始前**：步骤 0 的驱动就位

**操作**：

```bash
# 在 es-03 上执行（ubuntu）
sudo tee /etc/logstash/conf.d/ry-user.conf >/dev/null <<'EOF'
input {
  jdbc {
    jdbc_connection_string => "jdbc:mysql://10.0.0.150:3306/ry-cloud?useSSL=false&serverTimezone=Asia/Shanghai&characterEncoding=utf8"
    jdbc_user => "ry"
    jdbc_password => "【实验密码】"
    jdbc_driver_library => "/usr/share/logstash/vendor/jdbc/mysql-connector-j-8.0.33.jar"
    jdbc_driver_class => "com.mysql.cj.jdbc.Driver"

    statement => "SELECT user_id, user_name, nick_name, email, phonenumber, status, create_time FROM sys_user"
    schedule => "*/1 * * * *"

    use_column_value => true
    tracking_column => "user_id"
    tracking_column_type => "numeric"
    last_run_metadata_path => "/usr/share/logstash/.last_run_ry_user"
    clean_run => false
  }
}

output {
  elasticsearch {
    hosts => ["http://10.0.0.180:9200", "http://10.0.0.181:9200", "http://10.0.0.182:9200"]
    index => "ry-user"
    document_id => "%{user_id}"
  }
}
EOF

sudo systemctl restart logstash
sleep 40
sudo systemctl is-active logstash
```

**应该看到**：`active`。

触发一次同步（第一次要手动 restart 才会立刻跑），等 1 分钟看 ES：

```bash
# 在 es-03 上执行（ubuntu）
curl -s "http://10.0.0.180:9200/ry-user/_count?pretty"
```

**应该看到**：`"count": 1` 或更大（若依默认有一个 admin 用户）。

**失败怎么办**：
- `count: 0` → `sudo journalctl -u logstash -n 80 | grep -i -A5 error`，多半是 JDBC 连不上或驱动类名错
- `Unknown database 'ry-cloud'` → 库名带横线，URL 里不需要转义，确认拼写
- `Access denied` → 用 `ry` 用户密码 `【实验密码】`，或临时改用 root

## 步骤 2 · Nginx 加 ES 代理和搜索页（20 分钟）

**在哪台**：nginx-01（120）、nginx-02（121）
**目的**：让浏览器能查 ES（同源，避免 CORS）
**开始前**：步骤 1 的索引有数据

**操作**：

1. 写搜索页（两台都放）：

```bash
# 在 nginx-01 上执行（ubuntu）—— 121 同样执行
sudo mkdir -p /usr/share/nginx/html/search
sudo tee /usr/share/nginx/html/search/index.html >/dev/null <<'EOF'
<!doctype html>
<html lang="zh-CN">
<head>
<meta charset="utf-8">
<title>用户搜索（Elasticsearch）</title>
<style>
  body{font-family:system-ui;max-width:760px;margin:50px auto;padding:0 16px}
  input{width:70%;padding:8px;font-size:15px}
  button{padding:8px 16px;font-size:15px;cursor:pointer}
  table{width:100%;border-collapse:collapse;margin-top:20px;font-size:14px}
  th,td{border-bottom:1px solid #e5e7eb;padding:8px;text-align:left}
  .hint{color:#6b7280;font-size:13px}
</style>
</head>
<body>
<h2>用户搜索</h2>
<p class="hint">数据来自 Elasticsearch 索引 <code>ry-user</code>，由 Logstash 从 MySQL 同步</p>
<p>
  <input id="kw" placeholder="输入用户名或昵称，例如 admin" value="admin">
  <button onclick="search()">搜索</button>
</p>
<table>
  <thead><tr><th>user_id</th><th>用户名</th><th>昵称</th><th>手机</th><th>状态</th></tr></thead>
  <tbody id="rows"></tbody>
</table>
<script>
async function search() {
  const kw = document.getElementById('kw').value.trim() || '*';
  const body = kw === '*'
    ? { query: { match_all: {} }, size: 20 }
    : { query: { multi_match: { query: kw, fields: ['user_name', 'nick_name'] } }, size: 20 };

  const resp = await fetch('/es/ry-user/_search', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(body)
  });
  const data = await resp.json();
  const rows = document.getElementById('rows');
  rows.innerHTML = '';
  (data.hits ? data.hits.hits : []).forEach(h => {
    const s = h._source;
    rows.innerHTML += `<tr><td>${s.user_id}</td><td>${s.user_name}</td>
      <td>${s.nick_name ?? ''}</td><td>${s.phonenumber ?? ''}</td>
      <td>${s.status == 0 ? '正常' : '停用'}</td></tr>`;
  });
  if (!data.hits || data.hits.hits.length === 0) {
    rows.innerHTML = '<tr><td colspan="5">没有结果</td></tr>';
  }
}
search();
</script>
</body>
</html>
EOF
```

2. 在 Nginx 里加两段 location（**编辑现有 `ruoyi.conf`**）：

```bash
# 在 nginx-01 上执行（ubuntu）—— 121 同样执行
sudo tee /etc/nginx/conf.d/ruoyi.conf >/dev/null <<'EOF'
server {
    listen 80 default_server;
    server_name _;

    root /usr/share/nginx/html/ruoyi;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /prod-api/ {
        proxy_set_header Host $http_host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_pass http://10.0.0.130:8080/;
    }

    location /es/ {
        proxy_set_header Host $host;
        proxy_pass http://10.0.0.180:9200/;
    }

    location /search/ {
        root /usr/share/nginx/html;
        index index.html;
    }
}
EOF

sudo nginx -t && sudo systemctl reload nginx
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1/search/
curl -s "http://127.0.0.1/es/ry-user/_count"
```

**应该看到**：`200`；`{"count":1,...}`。

**失败怎么办**：
- `/es/` 返回 502 → ES 没起或 9200 不通
- 页面白屏 → F12 看 `/es/ry-user/_search` 的返回体和状态码

## 步骤 3 · 在若依里加"外链菜单"（5 分钟）

**在哪台**：Windows 浏览器（若依后台）
**目的**：让它看起来就是若依的一个功能
**开始前**：步骤 2 的 `/search/` 能打开

**操作**：

1. 若依后台 → `系统管理` → `菜单管理` → `新增`：

| 字段 | 值 |
|---|---|
| 菜单名称 | 用户搜索 |
| 上级菜单 | 主类目 |
| 菜单类型 | **外链** |
| 路由地址 | `http://192.168.10.119/search/` |
| 显示状态 | 显示 |
| 菜单图标 | search |

2. 保存 → 刷新页面（或重新登录）→ 左侧出现"用户搜索"，点开就是那个页面。

**应该看到**：点菜单后打开搜索页，输入 `admin` 能搜到。

**失败怎么办**：
- 点开 404 → 外链地址必须写完整 `http://192.168.10.119/search/`
- 左侧没出现 → `系统管理 → 角色管理` 给 admin 角色勾上这个菜单，重新登录

## 步骤 4 · 验证"数据真的来自 MySQL"（5 分钟）

**在哪台**：Windows + 终端
**目的**：证明同步链路是活的，不是假数据

**操作**：

1. 在若依里改一个昵称：`系统管理 → 用户管理 → admin → 修改 → 昵称改成 测试昵称A → 确定`
2. 等 1–2 分钟（Logstash 每分钟跑一次）
3. 打开搜索页搜 `测试昵称A`

**应该看到**：能搜到 admin 这一行。

命令行再确认一次：

```bash
# 在 bastion 上执行（ubuntu）
curl -s "http://10.0.0.180:9200/ry-user/_search?q=nick_name:测试昵称A" | grep -o '"nick_name":"[^"]*"'
```

**应该看到**：`"nick_name":"测试昵称A"`。

**失败怎么办**：
- 搜不到 → `curl http://10.0.0.182:9600/_node/stats/pipelines?pretty` 看 jdbc 管道有没有跑
- 中文搜不到 → 字段是 keyword 类型，用完整值搜；或改用 `match` 查询
