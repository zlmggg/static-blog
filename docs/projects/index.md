## 项目文章怎么写

::: details 新建项目文章时，复制这个结构
```markdown
---
category: 项目
difficulty: 中级
date: YYYY-MM-DD
---

# 项目名称

> 一句话说明这是什么、解决什么问题。

## 一、背景 / 目标
（为什么做，想达到什么效果）

## 二、架构 / 环境
（真实的机器、版本、网络拓扑，尽量写具体）

## 三、关键步骤
（分步骤，配可复制的命令 / 配置）

## 四、踩过的坑 & 解决
（现象 → 原因 → 怎么解决的）

## 五、成果 / 复盘
（做成了什么、学到什么、下次怎么更好）

## 六、相关链接
（代码仓库、相关速查 / 文章）
```
:::
