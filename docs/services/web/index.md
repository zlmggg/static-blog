# 接入与网络

> 服务详解分组 · 返回 [服务全景](/services/)
> 流量入口：反向代理、四层负载、高可用 VIP、域名解析。

## 组内选型导读

接入层决定流量怎么进来。Nginx 做七层路由与 TLS，LVS+Keepalived 做四层高可用 VIP，HAProxy 是纯负载替代，DNS 管解析。本站接入层就是 LVS+Nginx 两层，见组合方案。
