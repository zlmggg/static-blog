# Docker 02 · 部署方案

> 四篇制：[01 理论](./01-理论) · [02 部署](./02-部署) · [03 功能](./03-功能) · [04 实战](./04-实战)
> 本篇装 Docker Engine 并调好 daemon.json。原理见 [01 理论](./01-理论)。Compose 编排见 [Compose](/services/container/compose)，私有仓库见 [Harbor](/services/container/harbor)。

**先分清**：生产 Linux 用 **Docker Engine**（容器引擎）；Windows/mac 开发用 **Docker Desktop**（内置 Engine + GUI + K8s 的桌面工具）。本篇讲 Engine。

## 方案一 · 包管理安装（推荐）

**环境**：Rocky Linux 9 / Ubuntu 24.04，root 或 sudo。

### RHEL / Rocky 系

```bash
sudo dnf install -y dnf-utils
sudo dnf config-manager --add-repo https://mirrors.aliyun.com/docker-ce/linux/centos/docker-ce.repo
sudo dnf install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo systemctl enable --now docker
```

### Debian / Ubuntu

```bash
sudo apt update
sudo apt install -y ca-certificates curl gnupg
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://mirrors.aliyun.com/docker-ce/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/docker.gpg] https://mirrors.aliyun.com/docker-ce/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list
sudo apt update && sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo systemctl enable --now docker
```

装 `docker-compose-plugin` 后命令是 `docker compose`（带空格，官方插件），老的独立二进制 `docker-compose` 已淘汰。

### 验证

```bash
docker version          # Client + Server 版本
docker info             # 引擎详情：存储驱动/容器数/镜像数
docker run --rm hello-world   # 跑测试容器
```

把普通用户加进 docker 组可免 sudo：`sudo usermod -aG docker $USER`（重新登录生效）。注意 docker 组权限等同 root，只给可信用户。

## 方案二 · 二进制离线安装（无网环境）

内网机器不能上网时，下载静态二进制包手动装：

```bash
# 从 https://mirrors.aliyun.com/docker-ce/linux/static/stable/x86_64/ 下载
tar -xzf docker-27.x.tgz
sudo cp docker/* /usr/local/bin/
```

再手写 systemd 单元托管 dockerd：

```ini
# /etc/systemd/system/docker.service
[Unit]
Description=Docker Application Container Engine
After=network-online.target
Wants=network-online.target
[Service]
Type=notify
ExecStart=/usr/local/bin/dockerd -H unix:///var/run/docker.sock
ExecReload=/bin/kill -s HUP $MAINPID
Restart=on-failure
LimitNOFILE=infinity
Delegate=yes
KillMode=process
[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload && sudo systemctl enable --now docker
```

## 方案三 · 官方一键脚本

```bash
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
```

::: warning 脚本不认 Rocky
官方脚本当前不支持 Rocky Linux。Rocky 上要么用方案一的 yum 源，要么临时把 `/etc/os-release` 的 `ID=rocky` 改成 `ID=centos` 再跑脚本（装完改回）。
:::

## 核心配置 daemon.json（重点）

配置文件 `/etc/docker/daemon.json`，改完必须重载。**注意：多数配置只对新建容器生效，旧容器不生效。**

```json
{
  "registry-mirrors": ["https://docker.xuanyuan.me"],
  "insecure-registries": ["harbor.internal.local:80"],
  "log-driver": "json-file",
  "log-opts": { "max-size": "100m", "max-file": "3" },
  "exec-opts": ["native.cgroupdriver=systemd"],
  "data-root": "/data/docker",
  "live-restore": true,
  "max-concurrent-downloads": 10
}
```

```bash
sudo systemctl daemon-reload && sudo systemctl restart docker
docker info | grep -A5 "Registry Mirrors"
```

逐项的意义：

- **registry-mirrors（镜像加速）**：本站统一走**轩辕云代理**（有账号流量、速度快）。公共加速器现状见 [04 · 镜像加速](./04-实战)——大厂公共加速器 2024 年后批量关停，生产别依赖。
- **log-opts（日志轮转）**：容器 stdout 日志默认**无限增长，是生产磁盘写满的头号原因**，必须配 max-size/max-file。
- **cgroupdriver=systemd**：与 systemd 对齐 cgroup 管理，K8s 要求一致，避免两套 cgroup 驱动打架。
- **data-root**：Docker 数据目录，建议放独立大盘（默认 `/var/lib/docker` 容易撑爆系统盘）。
- **live-restore**：dockerd 重启时容器不停，提升可用性。
- **insecure-registries**：允许 HTTP 私有仓库（纯内网测试用，生产上 HTTPS）。

## 关于 No swap limit support

`docker info` 出现这条 WARNING 时，`--memory-swap` 不生效，需给内核开 swapaccount：编辑 `/etc/default/grub` 在 `GRUB_CMDLINE_LINUX` 加 `swapaccount=1`，然后 `sudo update-grub`（RHEL 系 `grub2-mkconfig -o /boot/grub2/grub.cfg`）并重启。重启后 WARNING 消失即生效。
