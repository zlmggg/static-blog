# Jenkins 02 · 部署方案

> 四篇制：[01 理论](./01-理论) · [02 部署](./02-部署) · [03 功能](./03-功能) · [04 实战](./04-实战)
> 本篇装 Jenkins 并接 agent。架构见 [01 理论](./01-理论)。

## 一、安装 Jenkins LTS

选 **LTS（长期支持版）**，别追 weekly。

### rpm（RHEL 系）

```bash
sudo wget -O /etc/yum.repos.d/jenkins.repo https://pkg.jenkins.io/redhat-stable/jenkins.repo
sudo rpm --import https://pkg.jenkins.io/redhat-stable/jenkins.io-2023.key
sudo dnf install -y jenkins java-17-openjdk
sudo systemctl enable --now jenkins        # 默认 8080
```

### Docker

```bash
docker run -d --name jenkins -p 8080:8080 -p 50000:50000 \
  -v jenkins_home:/var/jenkins_home \
  jenkins/jenkins:lts-jdk17
```

`jenkins_home` 卷持久化配置与 job，**一定要挂出来**，否则容器删了配置全丢。50000 是 agent JNLP 通信端口。

## 二、初始化

浏览器访问 `http://10.0.0.70:8080`，用初始密码解锁：

```bash
sudo cat /var/lib/jenkins/secrets/initialAdminPassword   # rpm
docker exec jenkins cat /var/jenkins_home/secrets/initialAdminPassword   # docker
```

选"安装推荐插件"，建管理员账号（**别用默认 admin**）。

## 三、推荐插件

- **Git / GitLab**：拉代码、webhook 触发。
- **Pipeline**：声明式流水线（核心）。
- **Credentials Binding**：凭据注入。
- **Docker Pipeline**：流水线里用 Docker。
- **Blue Ocean**：现代化流水线可视化界面。
- **SSH Agent**：SSH 凭据部署。

插件按需装，别贪多——插件越多升级兼容风险越大。

## 四、接入 agent

**master 不跑构建**（保稳定），构建分发到 agent。Manage Jenkins → Nodes → New Node：

- **SSH 方式**：填 agent 主机 IP + SSH 凭据，master 主动连过去起 agent 进程。
- **JNLP 方式**：agent 机器主动连 master 的 50000 端口（适合 agent 在 NAT 后）。

给 agent 打 **label**（如 `linux`、`docker`、`deploy`），流水线里 `agent { label 'docker' }` 按 label 调度到对应机器。

```groovy
pipeline {
  agent { label 'docker' }     // 只在带 docker 标签的 agent 跑
  stages { /* ... */ }
}
```
