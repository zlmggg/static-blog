## 统一四段模板

每个服务同一套顺序：**01 服务理论**（是什么/核心概念/架构/选型）→ **02 部署方案**（单机→主从→集群/容器化，环境→步骤→验证）→ **03 功能详解**（日常使用 + 专属命令中文详解 + 配置参数）→ **04 实战参考**（企业场景/FAQ/官方文档）。
