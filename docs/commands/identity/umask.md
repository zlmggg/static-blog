# umask · 默认权限掩码

> 命令手册 · [用户与权限](/commands/identity/) ｜ 频率：偶尔用
> 新建文件默认 644、目录默认 755，谁定的？umask。它决定"创建时默认给什么权限"。

## 一句话用途

设置新建文件/目录的默认权限掩码，控制默认开放程度。

## 高频场景速查

```bash
umask                # 看当前掩码（如 0022）
umask 027            # 设掩码：新文件 640，新目录 750
umask 077            # 严格：新文件 600，新目录 700（仅自己）
umask -S             # 符号形式显示（u=rwx,g=rx,o=）
```

## 计算方式

默认基准：文件 666（不给执行）、目录 777。**减去** umask 得实际权限：

| umask | 新文件 | 新目录 | 含义 |
|---|---|---|---|
| 022 | 644 | 755 | 默认，别人可读 |
| 027 | 640 | 750 | 组可读，其他人无 |
| 077 | 600 | 700 | 仅自己 |
| 002 | 664 | 775 | 组可写（协作） |

::: tip 为什么文件默认没有 x
文件基准是 666 不是 777——新建文件默认不给执行位（安全），需要执行再 chmod +x。目录基准 777（目录的 x 是"可进入"，必须给）。
:::

## 运维实战

**敏感目录严格默认**：在脚本开头 `umask 077`，生成的密钥/配置默认仅自己可读。
**团队协作目录**：`umask 002` + setgid，组内成员新建文件互相可写。
**全局设置**：`/etc/profile` 或 `/etc/login.defs` 的 UMASK；用户级 `~/.bashrc`。
