# 文件与文本

> 命令手册 · [返回总览](/commands/) ｜ 本组 38 个页面，按功能分类

## 功能

文件与文本命令是运维的"手"：找文件、看内容、过滤日志、改配置、打包传输都靠它。文本三剑客 grep/sed/awk 是日志分析与配置批量修改的核心，值得反复练。

## 类别

| 命令 | 用途 |
|---|---|
| [ls](./ls) | 列出目录内容 |
| [cd 与 pwd](./cd-pwd) | 切换与确认当前目录 |
| [mkdir / rmdir](./mkdir-rmdir) | 建删目录 |
