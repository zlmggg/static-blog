# 命令手册

> 定位：**查一个 OS 命令怎么用**。面向自己与新学运维的同学——高频场景复制即用，`--help` 参数全量中文详解，按"每天用 / 偶尔用 / 很少用"分级，降低英文阅读门槛。
> 服务命令（docker / kubectl / nginx…）不在这里，去 [服务详解](/services/)。

## 覆盖原则

1. **查看检测与操作变更并重**：磁盘不止 df/du，分区/格式化/挂载/LVM/修复都要会。
2. **同族命令合并成页**：fdisk/parted/gdisk → 分区工具，覆盖广但不碎片化。
3. **一条命令唯一主页**：跨组互链（lsof 主页在排障观测，网络组链接过去）。
4. **排序即学习顺序**：入门 → 高级，每组一篇导读页。

## 命令页模板

一句话用途 + 频率标记 → 高频场景速查 → 参数详解（`--help` 中文化三级分级）→ 运维实战 → 相关命令 + 官方文档。
