# nmap · 端口扫描与服务探测

> 命令手册 · [网络](/commands/network/) ｜ 频率：很少用
> 这台机开了哪些端口、跑什么服务？nmap 扫描探测。安全自查暴露面、排查端口连通都用它。

## 一句话用途

扫描目标开放的端口、识别服务与版本、做安全自查。

## 高频场景速查

```bash
nmap 10.0.0.11                   # 扫常见1000端口
nmap -p 80,443,3306 10.0.0.11    # 扫指定端口
nmap -p- 10.0.0.11               # 扫全部65535端口
nmap -sV 10.0.0.11               # 探服务版本
nmap -sS 10.0.0.11               # SYN 半开扫描（快，需 root）
nmap -O 10.0.0.11                # 操作系统识别
nmap -sn 10.0.0.0/24             # 只探活（ping 扫描）
nmap -sU -p 53,161 10.0.0.11     # UDP 扫描
nmap --script=vuln 10.0.0.11     # 漏洞脚本（授权才用）
```

## 参数详解

| 参数 | 含义 |
|---|---|
| `-p 端口` | 指定端口（-p- 全部） |
| `-sS` | SYN 扫描（默认 root） |
| `-sT` | TCP connect 扫描（无 root） |
| `-sU` | UDP 扫描 |
| `-sV` | 服务版本探测 |
| `-O` | 系统识别 |
| `-sn` | 只探活不扫端口 |
| `-T0~5` | 速度（T4 常用） |
| `--script` | NSE 脚本 |

## 运维实战

**安全自查暴露面**：`nmap -sV -p- 公网IP` 看对外开放了什么，关掉不必要的（数据库/Redis 不该对公网）。
**确认防火墙生效**：改完规则 nmap 扫，验证端口确实被挡。
**网段探活**：`nmap -sn 10.0.0.0/24` 看哪些主机在线。

::: danger 只扫授权目标
扫描他人网络可能违法/触发告警。只扫自己拥有或明确授权的目标。生产扫描避开高峰，-T4 别太激进触发 IDS。
:::
